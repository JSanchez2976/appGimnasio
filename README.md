# CalorieGraph

![CalorieGraph logo](app_gimnasio/assets/branding/calorie_graph.png)

Aplicación personal para registrar peso, calorías, medidas y consumo de agua,
seguir la evolución y configurar recordatorios.

Desarrollada con Flutter y Dart. Usa Firebase Authentication y Cloud Firestore
para la autenticación y sincronización de datos.

Las decisiones de funcionamiento y los supuestos de cálculo están en
[docs/funcionamiento.md](docs/funcionamiento.md).

La configuración actual de Firebase está preparada para Android.
